# Bi122Site

Course resources site for **Bi 122: Genetics** (Caltech, BBE).

Static site — plain HTML and CSS, no build step. Deploys to
[bi122resources.rishib.com](https://bi122resources.rishib.com) via Vercel on push to `main`.

```
index.html    syllabus, staff, office hours, grading, schedule
styles.css    design tokens and layout
```
